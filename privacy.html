Privacy Policy

Last updated: October 24, 2026

MS Health Archive is a private application used only by its owner, Matthew Sanders. It is not available to the public.

Data accessed

With the owner's consent, the app reads his own health and fitness data from the Google Health API, using read-only access. It does not write or change any data.

How data is used

The data is used only to keep a private archive and summaries for the owner's personal use. It is not sold, shared with third parties, or used for advertising.

Storage and security

Data and access credentials are stored privately on systems the owner controls, with access restricted to the owner and his personal assistant tools.

Revoking access

Access can be revoked at any time from the Google Account's third-party connections page, and archived data can be deleted on request.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
